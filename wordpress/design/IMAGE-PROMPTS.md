# Prompts pour les images

Généré automatiquement depuis les fiches de l'extension (ne pas modifier à la main).

Pour chaque contenu : un prompt pour la **photo principale** (format paysage 3:2, par exemple 1536 × 1024 px) et un prompt pour l'**image Pinterest** (format portrait 2:3, 1000 × 1500 px). Les prompts sont en anglais : les générateurs d'images les comprennent mieux.
